Problem
Надо пройтись по дереву и вывести сначала родителя потом левого ребенка потом правого. Всё это в список.

Approach
Я написала дополнительную функцию она сначала записывает текущий узел а потом вызывает себя для левого и правого ребенка.

Time Complexity
O(n). Мы каждый узел посещаем только один раз.

Reflection
Улучшить не получится потому что нам нужно обойти вообще все элементы чтобы собрать их в ответ. Так что O(n) это лучшее что есть
