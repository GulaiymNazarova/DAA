Problem
Надо перевернуть дерево. То есть поменять местами левых и правых детей на каждом уровне.

Approach
Я написала функцию которая просто берет и меняет местами ссылки. А потом делает то же самое для детей.

Time Complexity
O(n). Нам надо зайти в каждый узел чтобы поменять у него детей.

Reflections
Идей по улучшению нет так как дерево надо перевернуть полностью. Без обхода всех элементов это невозможно(скорее всего).
