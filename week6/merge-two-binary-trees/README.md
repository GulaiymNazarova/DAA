Problem
Дано два дерева. Надо их склеить в одно складывая числа там, где узлы совпадают.

Approach
Я написала функцию которая складывает числа из двух узлов. Если одного узла нет она просто возвращает другой. А потом так же склеивает их детей.

Time Complexity
O(n) где n это количество узлов в меньшем дереве потому что мы идем по ним одновременно.

Improvements
Кажется это уже хороший вариант. Мы все равно должны посмотреть на каждый узел чтобы сложить числа так что быстрее не выйдет.
