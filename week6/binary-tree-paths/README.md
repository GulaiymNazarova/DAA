Problem
Надо найти все пути от корня до листьев и вывести их в виде строк, где числа разделены стрелочками.

Approach
Я написала функцию, которая таскает с собой строку. Она добавляет туда числа и стрелочку, а когда доходит до листа, кидает эту строку в общий список.

Time Complexity
O(n). Нам нужно дойти до каждого листа, чтобы собрать все пути.

Improvements
Кажется быстрее нельзя потому что надо построить строки для всех путей. В коде я не меняла строку через StringBuilder, так что может быть по памяти не идеально.
