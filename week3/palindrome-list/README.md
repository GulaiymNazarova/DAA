# Palindrome Linked List

## 1. Problem

Дан связный список. Надо проверить, читается ли он одинаково слева направо и справа налево. То есть палиндром или нет.

## 2. Approach

Самое простое что придумала: скопировать все значения в ArrayList. В связном списке нельзя зайти с конца, а в ArrayList можно брать элементы по индексу. Поэтому сравнение с двух концов становится простым.

Прохожу список и складываю все val в список. Потом ставлю два индекса: left = 0, right = size - 1. Иду с двух сторон и сравниваю. Если значения не равны — возвращаю false. Если дошли до середины — true.

Пример 1 -> 2 -> 2 -> 1. ArrayList [1, 2, 2, 1].
left 0, right 3 — 1 и 1, равны.
left 1, right 2 — 2 и 2, равны.
left стал 2, right стал 1, цикл закончился. Возвращаю true.

Пример 1 -> 2 -> 3. ArrayList [1, 2, 3].
left 0, right 2 — 1 и 3, не равны. Возвращаю false сразу.

Проблема была с Integer. Сначала писала list.get(left) == list.get(right). На маленьких числах работало, на больших нет. Потому что Integer это объект и == сравнивает ссылки. Java кэширует числа только от -128 до 127. Поняла когда тестировала на списке с числом 200. Пришлось вытаскивать в int переменные, тогда работает нормально.

Пробовала ещё без ArrayList — найти середину и перевернуть половину списка. Но там столько возни с указателями, что я запуталась и сдалась. ArrayList проще.

## 3. Time Complexity

Time: O(n). Копирование O(n) и сравнение O(n), вместе O(n).
Space: O(n). Потому что ArrayList хранит все n значений.

## 4. Reflection

По времени нормально, но по памяти можно улучшить до O(1) если переворачивать половину списка на месте. Тогда время останется O(n) а память O(1). Но это сложнее и я не была уверена что не наделаю ошибок с указателями. Поэтому оставила простой вариант — он работает и понятный.
