# Remove Duplicates from Sorted List

## 1. Problem

Есть отсортированный связный список. Надо убрать повторяющиеся значения, чтобы каждое число осталось только один раз. Так как список отсортирован, одинаковые числа стоят рядом.

## 2. Approach

У меня два указателя: current и nextNode. Иду по списку и смотрю, совпадают ли значения у current и nextNode. Если совпадают — значит nextNode это дубликат, и я просто перекидываю current.next через него. Если не совпадают — двигаю оба указателя вперёд.

Например список 1 -> 1 -> 2 -> 3 -> 3:
- current на первой 1, nextNode на второй 1. Совпадают, убираем вторую.
- current на 1, nextNode на 2. Не совпадают, двигаемся.
- current на 2, nextNode на 3. Не совпадают, двигаемся.
- current на 3, nextNode на второй 3. Совпадают, убираем.
- nextNode стал null, цикл закончился.

Получилось 1 -> 2 -> 3.

Была проблема: сначала пробовала один указатель и писала current.next.next, но путалась когда подряд шло много одинаковых. С двумя указателями мне понятнее. Ещё ловила ошибку null на пустом списке, добавила проверку в начале.

## 3. Time Complexity

Time: O(n), потому что прохожу список один раз.
Space: O(1), потому что использую только два указателя, ничего не создаю.

## 4. Reflection

Быстрее чем O(n) быть не может, потому что каждый узел надо посмотреть хотя бы раз. Так что решение оптимальное. Можно было бы написать короче с одним указателем, но мне с двумя понятнее.
