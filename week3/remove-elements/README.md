# Remove Linked List Elements

## 1. Problem

Дан связный список и число val. Надо убрать из списка все узлы где значение равно val. Вернуть новую голову.

## 2. Approach

Сделала через dummy узел перед головой. Это такой искусственный узел, чтобы не мучиться со случаем когда надо удалить саму голову.

У меня два указателя: current стоит на узле перед проверяемым, check это тот узел который проверяю. Если check.val равен val — удаляю его, перекидываю current.next через него, а current не двигаю (потому что там может быть ещё один такой же). Если не равен — двигаю current на check.

Пример: список 1 -> 2 -> 6 -> 3 -> 6, val = 6.
- dummy -> 1. check на 1, не равно, двигаюсь.
- current на 1, check на 2, не равно, двигаюсь.
- current на 2, check на 6, равно. Удаляю. Список: 1 -> 2 -> 3 -> 6. current остаётся на 2.
- current на 2, check на 3, не равно, двигаюсь.
- current на 3, check на 6, равно. Удаляю. Список: 1 -> 2 -> 3.
- check стал null, цикл закончился.

Проблема была когда писала без dummy. Отдельно обрабатывала голову, а потом внутри цикла при удалении двигала current и пропускала узлы. Например на 6 -> 6 -> 6 удаляла только первый и третий. Поняла что при удалении нельзя двигать current, потому что следующий может быть тоже подходящий. С dummy это стало виднее.

## 3. Time Complexity

Time: O(n), прохожу список один раз.
Space: O(1), только dummy и два указателя.

## 4. Reflection

Быстрее нельзя, каждый узел надо проверить. Можно было бы рекурсией, но тогда память была бы O(n) на стек. Мой вариант лучше.
